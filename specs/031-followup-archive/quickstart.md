# Quickstart

1. Start backend with npm start and frontend with npm run dev:ui.
2. Set a future reminder with note; reload and verify it remains.
3. Set a past reminder through a test fixture and verify due indicator.
4. Archive, verify default inbox hides it, then restore.
5. Archive, insert/sync an incoming message, verify it returns to Inbox; outgoing must not restore it.
6. Run npm run test:persistence and npm run build:ui.
