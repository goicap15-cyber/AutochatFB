Design Philosophy

The interface should look like software designed by a professional product team,
not AI-generated artwork.

Avoid

- excessive gradients
- glowing borders
- neon colors
- colorful backgrounds
- random accent colors
- glassmorphism everywhere
- oversized shadows
- floating cards
- visual noise
- futuristic cyberpunk style
- Dribbble concepts
- Behance concept art

The UI should feel

calm
clean
confident
boring in a good way
enterprise-ready

Design Direction

This is a productivity application.

It should look like

Linear

NOT like

Dribbble
Behance
Landing page
Crypto dashboard
AI art
Futuristic dashboard

Users spend 8 hours/day using this application.

Visual comfort is more important than visual impressiveness.
